# 🏪 Tienda Natural - Sistema POS

Sistema de punto de venta completo para tiendas de productos naturales, desarrollado con React y Node.js.

## 🚀 Instalación y Uso Rápido

### Opción 1: Descarga Directa (Recomendado)
1. **Descarga el proyecto** como ZIP desde GitHub
2. **Extrae** el archivo ZIP en tu computadora
3. **Haz doble clic** en `start.bat`
4. **¡Listo!** La aplicación se instalará y ejecutará automáticamente

### Opción 2: Clonar con Git
```bash
git clone https://github.com/tu-usuario/tienda-natural.git
cd tienda-natural
# Ejecutar start.bat
```

## 📋 Requisitos del Sistema

- **Windows 10** o superior
- **Node.js** (se instala automáticamente si no lo tienes)
- **Navegador web** (Chrome, Firefox, Edge, etc.)

## 🎯 Archivos Principales

| Archivo | Descripción |
|---------|-------------|

## 🐛 Solución de Problemas

### Error: "Node.js no está instalado"
- Ejecuta `install-node.bat`
- O descarga Node.js desde: https://nodejs.org/

### Error: "Puerto en uso"
- Ejecuta `stop.bat` para detener servicios
- O cambia los puertos en la configuración

### La aplicación no abre automáticamente
- Abre tu navegador manualmente
- Ve a: http://localhost:5173

## 📞 Soporte

Si tienes problemas:
1. Revisa `INSTRUCCIONES.txt`
2. Verifica que Node.js esté instalado
3. Asegúrate de que los puertos 3000 y 5173 estén libres
