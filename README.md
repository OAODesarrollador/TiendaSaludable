# 🌿 Sistema de Gestión para Tienda de Productos Naturales

Sistema completo de punto de venta con gestión de inventario, generación de códigos EAN-13, y reportes avanzados.

## 🚀 Inicio Rápido

### Requisitos
- Node.js 18+
- npm

### Instalación

1. **Backend**
```bash
cd backend
npm install
npm run seed
npm start
```

2. **Frontend** (nueva terminal)
```bash
cd frontend
npm install
npm run dev
```

3. **Acceso**
- URL: http://localhost:3000
- Usuario: admin / Contraseña: admin123

## ✨ Características

- Punto de Venta con escaneo EAN-13
- Generación automática de códigos de barras
- CRUD completo de productos
- Tickets PDF descargables
- Reportes con gráficos
